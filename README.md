# লোকশিল্প (Lokoshilpo) — ই-কমার্স ওয়েবসাইট

এটি একটি সম্পূর্ণ স্ট্যাটিক (HTML/CSS/JS) ই-কমার্স ওয়েবসাইট। কোনো সার্ভার বা ডাটাবেজ ছাড়াই কাজ করে — কার্ট ও অর্ডার তথ্য ব্রাউজারের localStorage-এ সংরক্ষিত হয়। এটি Vercel-এর ফ্রি প্ল্যানে খুব সহজেই হোস্ট করা যায়।

## যা যা আছে

- **হোম পেজ** — হিরো সেকশন, ক্যাটাগরি, বাছাই করা পণ্য
- **শপ পেজ** — ক্যাটাগরি ফিল্টার, মূল্য ফিল্টার, সার্চ, সর্টিং
- **প্রোডাক্ট ডিটেইল পেজ** — বিস্তারিত বর্ণনা, পরিমাণ নির্বাচন, সম্পর্কিত পণ্য
- **কার্ট পেজ** — পরিমাণ পরিবর্তন, পণ্য মুছে ফেলা, সাবটোটাল হিসাব
- **চেকআউট পেজ** — ডেলিভারি ফর্ম, ক্যাশ অন ডেলিভারি / bKash / Nagad পেমেন্ট অপশন
- **অর্ডার কনফার্মেশন পেজ** — অর্ডার নম্বর ও সামারি
- **অ্যাবাউট ও কন্টাক্ট পেজ**
- মোবাইল-রেসপনসিভ ডিজাইন, সব ডিভাইসে কাজ করে

## নতুন পণ্য যোগ করবেন যেভাবে

`js/products.js` ফাইলটি খুলুন। `PRODUCTS` অ্যারেতে একই ফরম্যাটে একটি নতুন অবজেক্ট যোগ করুন (id অবশ্যই ইউনিক হতে হবে)। এতেই হোম, শপ, সার্চ ও প্রোডাক্ট পেজে নতুন পণ্যটি স্বয়ংক্রিয়ভাবে দেখা যাবে।

## Vercel-এ হোস্ট করার নিয়ম (lokoshilpo.com)

1. এই পুরো ফোল্ডারটি একটি নতুন GitHub রিপোজিটরিতে আপলোড করুন (অথবা Vercel CLI দিয়ে সরাসরি ডিপ্লয় করুন: `vercel` কমান্ড রিপোর ভেতরে রান করুন)।
2. [vercel.com](https://vercel.com)-এ লগইন করে "Add New Project" থেকে রিপোটি ইম্পোর্ট করুন। এটি একটি Static সাইট — কোনো Build Command বা Framework সিলেক্ট করার দরকার নেই ("Other" সিলেক্ট করলেই হবে)।
3. ডিপ্লয় হয়ে গেলে Vercel প্রজেক্ট সেটিংস থেকে **Domains** সেকশনে গিয়ে `lokoshilpo.com` যোগ করুন এবং সেখানে দেখানো DNS রেকর্ডগুলো (A/CNAME) আপনার ডোমেইন প্রোভাইডারের কাছে গিয়ে বসিয়ে দিন।

## সীমাবদ্ধতা ও পরবর্তী ধাপ

এটি একটি ফ্রন্টএন্ড-ভিত্তিক সাইট — বাস্তব ব্যবসার জন্য পরবর্তীতে যোগ করা ভালো হবে:
- **আসল পণ্যের ছবি** — এখন প্রতিটি পণ্যের জায়গায় রঙিন প্লেসহোল্ডার ব্যবহার করা হয়েছে; `js/products.js`-এ প্রতিটি প্রোডাক্টে একটি `image` ফিল্ড যোগ করে `product-thumb` ও `pd-gallery-main`-এ `<img>` ট্যাগ দিয়ে প্রতিস্থাপন করা যাবে।
- **স্বয়ংক্রিয় পেমেন্ট ভেরিফিকেশন** — এখন bKash/Nagad পেমেন্ট ম্যানুয়ালি ট্রানজেকশন আইডি দেখে যাচাই করতে হবে। SSLCommerz, bKash Merchant API বা aamarPay-এর মতো পেমেন্ট গেটওয়ে যোগ করতে একটি ব্যাকএন্ড (যেমন Vercel Serverless Functions) প্রয়োজন হবে।
- **অ্যাডমিন প্যানেল ও ডাটাবেজ** — অর্ডার এখন শুধু ক্রেতার নিজের ব্রাউজারে সংরক্ষিত থাকে, আপনার কাছে পৌঁছায় না। প্রকৃত অর্ডার ম্যানেজমেন্টের জন্য একটি ডাটাবেজ (যেমন সহজে ব্যবহারযোগ্য Supabase বা Google Sheets-ভিত্তিক সমাধান) ও একটি নোটিফিকেশন সিস্টেম (ইমেইল/SMS) যোগ করা দরকার হবে।
- **কাস্টমার লগইন/অর্ডার হিস্ট্রি** — বর্তমানে চেকআউট গেস্ট হিসেবে হয়; চাইলে পরে লগইন সিস্টেম যোগ করা যাবে।
